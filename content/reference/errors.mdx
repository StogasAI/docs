Errors use the OpenAI error object:

```jsonc
{
	"error": {
		"message": "API key spend limit exceeded", // For people. The text can change.
		"type": "billing_error",
		"code": "key_spend_limit", // Stable. Handle errors by status and code.
		"param": null // The request field that caused the error, when known.
	}
}
```

Every gateway error has a code from the lists below. A provider error keeps the provider's code and
message when they help you fix the request, and otherwise has `"code": null`. Provider credentials
and internal details are never shown.

After a stream starts, its HTTP status cannot change, and an error arrives as an event in the
stream. See [Streaming](/docs/streaming#handle-errors).

## Error codes

Codes that start with a scope come from a [policy](/docs/policies) at that scope: `organization`,
`folder`, `grant`, `role`, `member`, `credential` or `key`. For example, `grant_spend_limit` means
that a grant's spending limit is reached.

### 400 Bad request

Fix the request before you send it again. Requests rejected before dispatch cost nothing.

| Code                          | Meaning                                                                                                            |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `invalid_json`                | The body is not valid JSON.                                                                                        |
| `invalid_request`             | A field is unknown or invalid, or the selected deployment cannot accept it. `param` names the field when known.    |
| `unsupported_request`         | The endpoint does not support this kind of request.                                                                |
| `model_unavailable`           | No deployment can serve the request. Check the model ID, credentials and routing policies.                         |
| `model_retired`               | The model or deployment retired; the message gives the date. Choose another [model](/docs/models).                 |
| `model_ambiguous`             | Several models match the request. Name one, or add a routing `order` or `sort`; see [Models](/docs/models#groups). |
| `provider_not_allowed`        | The model is not available from the requested provider.                                                            |
| `provider_unavailable`        | The requested provider is not available.                                                                           |
| `service_tier_unavailable`    | Your key can use the model only at other [service tiers](/docs/service-tiers).                                     |
| `unsupported_service_tier`    | The `service_tier` value is not one of the [supported values](/docs/service-tiers#select-a-tier).                  |
| `reasoning_mode_unavailable`  | Your key can use the model only in the other [`reasoning.mode`](/docs/reasoning#select-pro-mode).                  |
| `unsupported_reasoning_mode`  | `reasoning.mode` is not `standard` or `pro`.                                                                       |
| `unsupported_tool`            | The request uses an [unavailable tool](/docs/model-tools#unavailable-tools) or one its deployments do not run.     |
| `parameter_limit_exceeded`    | A token limit, such as `max_output_tokens`, is outside the range that the deployment allows.                       |
| `byok_required`               | The provider needs [your own credential](/docs/byok) on this key.                                                  |
| `byok_target_unavailable`     | No credential on the key provides this model. Check each credential's Region, hostings and Azure deployments.      |
| `byok_target_changed`         | Azure now serves another model, version or SKU from the chosen deployment. Choose its new Azure target.            |
| `byok_not_allowed`            | The key does not allow this credential.                                                                            |
| `encryption_key_required`     | An [encrypted policy or credential](/docs/customer-encryption) needs its key in `encryption_keys`.                 |
| `encrypted_content_invalid`   | Encrypted policy content cannot be read.                                                                           |
| `input_ascii_required`        | A policy [allows only ASCII input](/docs/pii-redaction#ascii-only-input).                                          |
| `key_configuration_too_large` | The key's policies and credentials are too large. Remove some of them.                                             |
| `policy_work_limit_exceeded`  | The policies that apply need too much work for one request. Simplify them.                                         |
| `invalid_policy`              | Only from [Validate policy](/docs/reference/policies/validatePolicy): the policies are invalid.                    |
| `byok_key_unregistered`       | The organization policy no longer registers the key that encrypted the credential, so requests skip it.            |
| `credential_stored`           | We store the credential you [check](/docs/reference/credentials/checkCredential); check it on the dashboard.       |

### 401 Unauthorized

| Code                  | Meaning                                                                                                               |
| --------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `invalid_api_key`     | The API key is missing, wrong or deleted.                                                                             |
| `invalid_check_grant` | The grant to [check a credential](/docs/reference/credentials/checkCredential) is invalid or expired.                 |
| `key_secret_replaced` | The key's secret was rotated, or GitHub [found it in public](/docs/api-keys#leaked-secrets). Copy the current secret. |

### 402 Payment required

| Code                   | Meaning                                                                     |
| ---------------------- | --------------------------------------------------------------------------- |
| `insufficient_balance` | The organization needs more [credit](/docs/billing).                        |
| `<scope>_spend_limit`  | A spending limit at that scope is reached. Adding credit does not raise it. |

### 403 Forbidden

| Code                      | Meaning                                                                                                                                                                        |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `<scope>_disabled`        | That scope is disabled.                                                                                                                                                        |
| `<scope>_expired`         | That scope's access has expired.                                                                                                                                               |
| `organization_restricted` | The organization is restricted, so its requests are refused until the restriction is lifted.                                                                                   |
| `schedule_denied`         | A [deny period](/docs/policies/access#deny-periods) blocks requests now.                                                                                                       |
| `dashboard_key_denied`    | Your dashboard session cannot use this key.                                                                                                                                    |
| `permission_denied`       | The key does not allow a [request policy](/docs/policies/request-policies), or you cannot manage the credential that you [check](/docs/reference/credentials/checkCredential). |
| `organization_inactive`   | The organization of the credential that you [check](/docs/reference/credentials/checkCredential) is inactive.                                                                  |

### 404, 405, 408 and 415

| Status | Code                     | Meaning                                                                                                                 |
| -----: | ------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
|  `404` | `route_not_found`        | The path does not exist.                                                                                                |
|  `404` | `credential_not_found`   | The credential that you [check](/docs/reference/credentials/checkCredential) was deleted, or you left its organization. |
|  `405` | `method_not_allowed`     | The path does not accept this HTTP method.                                                                              |
|  `408` | `request_body_timeout`   | The request body took longer than five minutes.                                                                         |
|  `415` | `unsupported_media_type` | `Content-Type` is not `application/json`.                                                                               |

### 409 Conflict

| Code                 | Meaning                                                                                                                                 |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `credential_changed` | The credential changed, or another check finished, while you [checked](/docs/reference/credentials/checkCredential) it. Check it again. |

### 413 Content too large

| Code                | Meaning                                                                                                                                |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `request_too_large` | The body is above a [request limit](/docs/reference/security#limits), or [redaction](/docs/pii-redaction#errors) reached a scan limit. |

### 429 Too many requests

Wait for the number of seconds in `Retry-After` when it is present. Requests that a limit blocks
at the same moment get waits up to a second apart, so their retries do not all arrive together. A
gateway `429` has `X-Should-Retry: false` when waiting will not help, such as a request larger than
its token limit, or when the wait is longer than a minute.

| Code                        | Meaning                                                                                                                           |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `<scope>_rate_limited`      | A [request rate limit](/docs/policies/limits) at that scope is reached.                                                           |
| `platform_rate_limited`     | The organization's requests are above the [platform rate](/docs/policies/limits#requests).                                        |
| `<scope>_token_limit`       | A token quota at that scope is reached.                                                                                           |
| `<scope>_concurrency_limit` | Too many requests are running at that scope.                                                                                      |
| `ip_rate_limit_exceeded`    | Too many requests from your IP address. See [API security](/docs/reference/security#limits).                                      |
| `upstream_rate_limit_error` | The provider's rate limit is reached.                                                                                             |
| `rate_limit_exceeded`       | Too many requests reached one gateway, or a request with the same key was just [blocked](/docs/policies/limits#blocked-requests). |

| `region_unavailable` | The service is not available where you are. See [Availability](/docs/availability). |

| Code                                                | Meaning                                                               |
| --------------------------------------------------- | --------------------------------------------------------------------- |
| `internal_error`                                    | An unexpected gateway failure.                                        |

### 502 Bad gateway

| Code                             | Meaning                                                                        |
| -------------------------------- | ------------------------------------------------------------------------------ |
| `upstream_authentication_failed` | The provider rejected the credential.                                          |
| `upstream_quota_exceeded`        | The provider account has no quota left.                                        |
| `upstream_access_denied`         | The credential cannot use the requested model.                                 |
| `upstream_protocol_error`        | The provider sent an invalid response over its confidential connection.        |
| `null`                           | Another provider failure, such as a dropped connection or an invalid response. |

### 503 Service unavailable

Send the request again later. The gateway did not send these requests to a model.

| Code                            | Meaning                                                                                       |
| ------------------------------- | --------------------------------------------------------------------------------------------- |
| `gateway_unavailable`           | The gateway is temporarily unavailable.                                                       |
| `gateway_draining`              | The gateway is shutting down for an update. Send new work on a new connection.                |
| `gateway_capacity_exceeded`     | The gateway is too busy to accept the request now, or needed the memory a slow upload held.   |
| `ip_admission_unavailable`      | The gateway cannot track new IP addresses now.                                                |
| `key_configuration_changed`     | The key changed, and the gateway is loading the new version.                                  |
| `byok_unavailable`              | Your provider credential is unavailable.                                                      |
| `upstream_capacity_unavailable` | The provider has no capacity now.                                                             |
| `upstream_verification_failed`  | The provider's confidential evidence did not verify, so the gateway did not send the request. |
| `upstream_configuration_error`  | Our provider configuration is unavailable.                                                    |

A `503` with `"code": null` comes from the provider, and the request may have reached it.

### 504 and 529

| Status | Code              | Meaning                                                                              |
| -----: | ----------------- | ------------------------------------------------------------------------------------ |
|  `504` | `request_timeout` | A [timeout](/docs/policies/timeouts) expired. Generation may continue and be billed. |
|  `529` | `null`            | The provider is overloaded.                                                          |

## Retries

The gateway retries and tries other deployments as your
[routing policy](/docs/policies/routing#retries-and-fallbacks) allows. If every call fails, the
response has the error of the last provider call, or the gateway's own error when no call reached
a provider.

A retry from your client is a new request, billed on its own. If the connection drops after the
request was sent, the model may already have run. Check the request in [Analytics](/docs/analytics)
before you send it again.

When a provider answers `429`, `503` or `529` with a wait, the gateway passes it on in
`Retry-After` as it does its own waits: in whole seconds, and up to a second apart for requests
refused together. Responses with `upstream_authentication_failed`, `upstream_quota_exceeded` or
`upstream_access_denied` carry `X-Should-Retry: false`, because a retry fails until the provider
credential or account changes. The OpenAI and Anthropic SDKs read both headers, and E2EE responses
carry them too.
