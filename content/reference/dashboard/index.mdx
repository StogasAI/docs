title: Dashboard API
description: Manage organizations, members, API keys, policies, balance, analytics and activity from your own programs.
---

The base URL is `https://app.stogas.ai`. Send an access token as `Authorization: Bearer <token>`.
Create a token on the **Account** page, or sign in with the [CLI](/docs/cli#use-your-account) and send
requests with `stogas api`. Each request acts as the user who created the token, with that user's
roles. Browsers do not let web pages on other sites call the API, so call it from a server or a
script.

## Access tokens

- A **Read only** token can call only `GET` operations. Operations with the scope `write` return
  `403 TOKEN_READ_ONLY` to it.
- A token for **Selected organizations** covers up to 30 of them and gets `404` for every other
  organization. Operations with the scope `all-organizations` return
  `403 TOKEN_ORGANIZATIONS_LIMITED` to it.
- An organization can turn off **Allow access tokens** in its settings. Its operations then return
  `403 ACCESS_TOKENS_NOT_ALLOWED` to every token at once, and a token can't select it.
  `GET /api/organizations` still lists it, with `allowAccessTokens` set to `false`. The dashboard
  and API keys aren't affected.
- A token stops working when it expires, when you delete it, and when you change your password.
- After you rotate a token on the **Account** page, requests with the old token return
  `401 TOKEN_REPLACED`.
- When GitHub finds a token in public, we replace it. Requests with the old token return
  `401 TOKEN_EXPOSED` and the place where GitHub found it until you reveal or rotate the new one on
  the **Account** page.

Tokens cannot create, reveal or rotate tokens, change sign-in methods, delete the account or use the
Playground. Use the dashboard for those.

## Organizations

Paths that start with `/api/{orgId}` act on one organization. `GET /api/organizations` lists the
organizations that your token covers: your personal organization first, then the others by name, up
to 100 on each page. Set `search` to find organizations by part of their name. You can belong to up
to 1,000 organizations, or as many as we agreed for your account.

## Lists

Lists return their entries in `items`. If `nextCursor` is not `null`, send it as the `cursor` query
parameter to get the next page.

## Errors

Every error has a JSON body with a `message`, and most have a `code` that a program can check. When
the code is `INVALID_REQUEST`, `issues` lists each field to fix.

Until an organization is [active](/docs/billing), its operations return `409 ORGANIZATION_INACTIVE`,
except those for its balance, payments and billing details, and leaving it.

## Limits

Each user can send 60 requests a minute, shared by the dashboard and all of the user's tokens.
Further requests return `429 RATE_LIMITED` with `Retry-After`. [Analytics](/docs/analytics) queries
and downloads have lower limits of their own.
