title: API Reference
description: API endpoints, with an interactive playground.
---

The base URL is `https://api.stogas.ai`. Send your API key from the
[dashboard](https://app.stogas.ai) as `Authorization: Bearer <api_key>`; `/v1/catalog` and
`/v1/models` need no key. Each endpoint page has a playground that sends live requests, and
inference requests from it are billed.
