---
title: Verify a gateway
description: Protect a request and verify the gateway that handles it.
---

Stogas can verify the gateway before it receives your API key or prompt. Verification checks that
the gateway is running approved open-source code inside genuine confidential-computing hardware.

You do not need verification to make a normal OpenAI-compatible request. Add it when you want your
application—not Stogas—to check the gateway and protect the connection.

## Fastest option: use the CLI

The CLI creates a verified local OpenAI-compatible endpoint. Your application only changes its base
URL.

1. Download `stogas-verify` from
   [GitHub Releases](https://github.com/StogasAI/verifier/releases).
2. Start the local endpoint:

```console
stogas-verify serve
```

3. Point your OpenAI-compatible client to the URL printed by the command:

```console
export OPENAI_API_KEY="$STOGAS_API_KEY"
export OPENAI_BASE_URL="http://127.0.0.1:8787/v1"
```

The CLI keeps verification current, refuses expired or invalid evidence, and preserves streaming.
See the [CLI guide](/docs/cli) for browser access, security modes, and response-receipt checks.

## Add verification to your application

Use a Stogas SDK when verification should run inside your process. The SDK verifies the available
gateways, opens a protected connection, and then lets your existing OpenAI client send normal Chat
Completions or Responses requests.

## What a successful check means

A successful check confirms that:

- the gateway software matches an approved public release;
- genuine AMD confidential-computing hardware started that software;
- the gateway's connection, encryption, and response-signing keys belong to that running instance;
  and
- the evidence is recent and has not expired.

Each protected response also includes a compact response receipt. You can verify that receipt now
or later to confirm which gateway handled the exact request and response.

For the full guarantees and limits, see the [security and trust model](/docs/confidential-security-model).
