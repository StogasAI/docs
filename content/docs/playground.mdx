Open **Playground** in your organization to chat with a model through one of your API keys. Its
requests are requests of that key, so the key's policy and limits apply to them.

## Assistant

The assistant answers questions about Stogas and your organization from the documentation and the
[dashboard API](/docs/reference/dashboard), and makes changes when you allow them. Turn it on with
**Assistant** above the conversation.

Each answer is one or more requests to the model you chose, with your reasoning, output limit and
system prompt, through the API key you chose. The model must accept function tools on Chat
Completions. Some models refuse them, or accept them only with reasoning **Off**; then the answer
shows the provider's error. The key's policy must allow the model, and the requests cost what other
requests to it cost. An answer makes at most 12 requests, and stops if it has no answer by then.

The assistant acts as you, so it can read and change only what your roles allow. What it reads, such
as a key's policy or the organization's members, goes to the model in its next request.

### Changes wait for you

The assistant reads documentation pages and dashboard data at once. A change waits for you: the
Playground shows what the assistant says it does, a link to the resource, the request, and what
changes. A policy shows against the policy now, other fields show their current and new values, and
a list of resources links each one. Choose **Allow** or **Deny**. A denied change does not run, and
the assistant reads that you denied it. **Stop** ends the answer, and a change that waits does not
run.

When a change is done, the Playground links the resource it changed, and the other dashboard pages
show the change without a reload.

### Questions

When your request leaves a choice open, such as which key a limit applies to, the assistant asks
before it acts. Pick an option, or answer in your own words.

The assistant never reads the secret of a new key or the code of an invitation: the Playground
removes them from responses first. It never reveals a key's secret, adds or changes a
[BYOK](/docs/byok) credential, or leaves the organization, because it does not call those
operations.

### Ask about a key or grant

**Ask the assistant** on the page of an API key or grant opens the Playground with the assistant on
and that key or grant beside the message box, so "this key" or "this grant" means it. Remove it to
ask about something else.

### Allow the assistant

The assistant is off in an organization until a member who can manage it turns on **Allow the
assistant** in **Settings**. [Activity](/docs/activity) records the change. Personal organizations
always allow it.
