Our SDK verifies approved gateway code, genuine confidential hardware and fresh session keys before
sending your API key or prompt. Ordinary HTTPS remains available for clients that do not use it.

## Use the CLI

Download `stogas` from [GitHub Releases](https://github.com/StogasAI/verifier/releases), then run:

```console
stogas serve
```

Pass the complete printed URL, including its random capability, to your OpenAI-compatible client.
Disable the client's automatic retries. The CLI preserves streaming and manages verified reusable
connections. See the [CLI guide](/docs/cli) for configuration and browser access.

Native SDKs use [attested TLS](/docs/attested-tls) by default. Browser and Fetch integrations use
[E2EE over HTTPS](/docs/e2ee). Both verify the
selected gateway before releasing credentials or content. Reuse one transport and close it during
application shutdown.

## Request a receipt

Send `Stogas-Metadata: v1` for a final `stogas` object with useful request metadata and a compact
response receipt. Buffered responses append it to JSON. Streams carry it in an SSE comment before
the terminal event. The SDK verifies requested receipts before reporting normal completion.

One signature covers the exact request and response hashes and the canonical `stogas` metadata,
excluding the receipt itself. Keep the original bytes, complete metadata and boot evidence to verify
it later. Provider-specific fields, when present, are covered by the same signature.

Offline archive verification checks the boot at its authenticated log time. Keep the boot archive
and the evidence bundle it references alongside the receipt; a later collateral refresh does not
change those records. The CLI's `proof` command and the SDK's archive verification APIs use this path.

A connection failure after submission can leave execution unknown. A failed final receipt does not
mean the model request never ran. Neither case should trigger an automatic inference retry.

See the [security and trust model](/docs/confidential-security-model) for the guarantees and limits.
