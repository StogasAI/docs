---
title: More Languages
description: Choose a complete native integration example for your runtime.
---

Use a language package where one is available, the C interface for native
embedding, or the verifier CLI as a supervised child process. Each guide includes
request code, streaming and cleanup. Verification stays in the same Rust core.

| Language                                                               | Integration                               |
| ---------------------------------------------------------------------- | ----------------------------------------- |
| [Kotlin](/docs/kotlin), [Scala](/docs/scala), [Clojure](/docs/clojure) | Java transport package and OpenAI client  |
| [F#](/docs/fsharp)                                                     | .NET transport package and OpenAI client  |
| [Objective-C](/docs/objective-c)                                       | C interface with Foundation and libcurl   |
| [Dart](/docs/dart)                                                     | C interface and OpenAI Dart client        |
| [Zig](/docs/zig)                                                       | C interface and libcurl                   |
| [PHP](/docs/php)                                                       | FFI and OpenAI PHP client                 |
| [Julia](/docs/julia)                                                   | C interface, OpenAI.jl and streaming HTTP |
| [Haskell](/docs/haskell)                                               | C interface and streaming HTTP            |
| [OCaml](/docs/ocaml)                                                   | ctypes and streaming HTTP                 |
| [LuaJIT](/docs/luajit)                                                 | FFI and streaming HTTP                    |
| [Elixir](/docs/elixir)                                                 | Supervised CLI and OpenAI Elixir client   |
| [Erlang](/docs/erlang)                                                 | Supervised CLI and Gun HTTP               |

For another runtime, use the complete [C example](/docs/c-cpp) and
[CLI guide](/docs/cli) as integration references. The C interface owns the
transport; callers own returned strings and handles and must free them as shown.

Each language guide includes its configuration entry point. The [shared workload settings](/docs/sdk-overview#choose-settings-for-your-workload) explain the four-channel default, application concurrency, deadlines and caller-owned retry policy.
