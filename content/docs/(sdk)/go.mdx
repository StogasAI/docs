The Go package runs a local connection to a verified gateway. Point the OpenAI client at its URL,
and keep using Chat Completions and Responses as usual.

## Install

```console
go get github.com/StogasAI/stogas/go github.com/openai/openai-go/v3
```

The package links the Stogas Rust library with cgo, so turn cgo on and install a C compiler. On
Alpine and other musl systems, build with `-tags musl`.

## Send a request

Create one transport and one client, and reuse them for every request:

```go
package main

import (
	"context"
	"fmt"
	"net/http"
	"os"

	"github.com/StogasAI/stogas/go"
	"github.com/openai/openai-go/v3"
	"github.com/openai/openai-go/v3/option"
	"github.com/openai/openai-go/v3/responses"
)

func run(ctx context.Context) error {
	// Checks the gateway, then connects with attested TLS.
	transport, err := stogas.NewTransport(stogas.TransportOptions{})
	if err != nil {
		return err
	}
	defer transport.Close()
	baseURL, err := transport.BaseURL() // A local URL with a random secret.
	if err != nil {
		return err
	}

	network := http.DefaultTransport.(*http.Transport).Clone()
	network.Proxy = nil // Do not send the local URL through a proxy.
	client := openai.NewClient(
		option.WithAPIKey(os.Getenv("STOGAS_API_KEY")),
		option.WithBaseURL(baseURL),
		option.WithMaxRetries(0), // A retried request can run twice.
		option.WithHTTPClient(&http.Client{
			Transport: network,
			// A redirect would send the request again.
			CheckRedirect: func(*http.Request, []*http.Request) error { return http.ErrUseLastResponse },
		}),
	)

	response, err := client.Responses.New(ctx, responses.ResponseNewParams{
		Model: "chutes-gemma-4-31b-turbo",
		Input: responses.ResponseNewParamsInputUnion{OfString: openai.String("Say hello in one sentence.")},
	})
	if err != nil {
		return err
	}
	fmt.Println(response.OutputText())
	return nil
}

func main() {
	if err := run(context.Background()); err != nil {
		fmt.Fprintln(os.Stderr, err)
		os.Exit(1)
	}
}
```

The local URL accepts Chat Completions, Responses and the policy check endpoint. Requests through it
can run for up to one hour. Set a shorter deadline with the request `context.Context` or
`http.Client.Timeout`.

## Stream and cancel

```go
stream := client.Chat.Completions.NewStreaming(ctx, openai.ChatCompletionNewParams{
	Model:    "chutes-gemma-4-31b-turbo",
	Messages: []openai.ChatCompletionMessageParamUnion{openai.UserMessage("Say hello.")},
})
defer stream.Close()
for stream.Next() {
	for _, choice := range stream.Current().Choices {
		fmt.Print(choice.Delta.Content)
	}
}
if err := stream.Err(); err != nil {
	return err // The stream did not complete.
}
```

Cancel `ctx` to stop a request. Output from a cancelled request is incomplete, and the request can
still be billed. See [Streaming](/docs/streaming).

## Options

```go
transport, err := stogas.NewTransport(stogas.TransportOptions{Security: "e2ee", MaxConnections: 4})
```

| Option           | Effect                                                                                                  |
| ---------------- | ------------------------------------------------------------------------------------------------------- |
| `Security`       | `"tls"` (default) or `"e2ee"`. See [Connection modes](/docs/connection-modes).                          |
| `MaxConnections` | The most connections to open, as needed. Default `4`.                                                   |
| `BaseURL`        | Another HTTPS origin, with no path. The trusted evidence does not change.                               |
| `Proxy`          | A SOCKS5 proxy for every connection. See [Connect through Tor](/docs/sdk-overview#connect-through-tor). |
| `Onion`          | `true` to reach Stogas at its onion address through `Proxy`.                                            |

`transport.RefreshEvidence()` loads new evidence now. See
[Connection settings](/docs/sdk-overview#connection-settings) for limits that apply to every SDK.

## Receipts

Send `Stogas-Metadata: v1` to get a signed [receipt](/docs/receipts):

```go
response, err := client.Responses.New(ctx, params, option.WithHeader("Stogas-Metadata", "v1"))
```

The transport checks the receipt before it returns the response. If the check fails, the request
fails, and the transport does not send it again.

## Check evidence offline

Check a saved receipt later, with the boot record and evidence files from
[Check without network access](/docs/receipts#check-without-network-access). This makes no network requests:

```go
verifier, err := stogas.NewEvidence(stogas.EvidenceOptions{Environment: "prod"})
if err != nil {
	return err
}
defer verifier.Close()

// stogasObject is the saved `stogas` object. The hashes are SHA-256 of the exact request
// body and of the response without its `stogas` object.
receipt, err := verifier.VerifyReceiptArchive(bootBytes, evidenceBytes, stogasObject,
	sha256.Sum256(requestBytes), sha256.Sum256(responseBytes))
```

`VerifyReceiptArchive` checks the boot against the evidence that was valid when it was logged. To
check current evidence instead, call `verifier.Refresh(evidenceBytes)`, then `VerifyLoggedBoot` or
`VerifyReceipt` on the snapshot it returns. Close each snapshot when you finish with it.
