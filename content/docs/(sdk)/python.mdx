The `stogas` package runs a local connection to a verified gateway. Point the OpenAI client at its
URL, and keep using Chat Completions and Responses as usual.

## Install

```console
pip install stogas openai
```

## Send a request

Create one transport and one client, and reuse them for every request:

```python
import os

from openai import DefaultHttpxClient, OpenAI
from stogas import Transport

transport = Transport()  # Checks the gateway, then connects with attested TLS.
client = OpenAI(
    api_key=os.environ["STOGAS_API_KEY"],
    base_url=transport.base_url,  # A local URL with a random secret.
    max_retries=0,  # A retried request can run twice.
    http_client=DefaultHttpxClient(
        trust_env=False,  # Do not send the local URL through a proxy.
        follow_redirects=False,  # A redirect would send the request again.
    ),
)

try:
    response = client.responses.create(
        model="chutes-gemma-4-31b-turbo",
        input="Say hello in one sentence.",
    )
    print(response.output_text)
finally:
    client.close()
    transport.close()
```

The local URL accepts Chat Completions, Responses and the policy check endpoint. Requests through it
can run for up to one hour; the OpenAI client's own timeout is 10 minutes unless you set `timeout`.

## Stream and cancel

```python
with client.chat.completions.create(
    model="chutes-gemma-4-31b-turbo",
    messages=[{"role": "user", "content": "Say hello."}],
    stream=True,
) as stream:
    for chunk in stream:
        for choice in chunk.choices:
            print(choice.delta.content or "", end="", flush=True)
```

Leaving the `with` block early cancels the request. Output from a cancelled request is incomplete,
and the request can still be billed. See [Streaming](/docs/streaming).

## Async

`Transport()` and `close()` block while they start and stop the connection, so run them in a
thread:

```python
import asyncio

from openai import AsyncOpenAI, DefaultAsyncHttpxClient


async def main() -> None:
    transport = await asyncio.to_thread(Transport)
    client = AsyncOpenAI(
        api_key=os.environ["STOGAS_API_KEY"],
        base_url=transport.base_url,
        max_retries=0,
        http_client=DefaultAsyncHttpxClient(trust_env=False, follow_redirects=False),
    )
    try:
        response = await client.responses.create(
            model="chutes-gemma-4-31b-turbo", input="Say hello."
        )
        print(response.output_text)
    finally:
        await client.close()
        await asyncio.to_thread(transport.close)
```

## Options

```python
transport = Transport(security="e2ee", max_connections=4)
```

`Transport` takes every [option](/docs/sdk-overview#options) as a keyword.
`transport.refresh_evidence()` loads new evidence now. If the transport can't start or refresh, it
raises `VerificationError` with a stable `code`, such as `"evidence_unavailable"`.

## Receipts

Send `Stogas-Metadata: v1` to get a signed [receipt](/docs/receipts):

```python
response = client.responses.create(
    model="chutes-gemma-4-31b-turbo",
    input="Say hello.",
    extra_headers={"Stogas-Metadata": "v1"},
)
```

The transport checks the receipt before it returns the response. If the check fails, the request
fails, and the transport does not send it again.

## Check evidence offline

Check a saved response later, with the boot record and evidence files from
[Check without network access](/docs/receipts#check-without-network-access). This makes no network requests:

```python
from hashlib import sha256

from stogas import EvidenceVerifier, VerificationError

verifier = EvidenceVerifier()  # Trusts our built-in root key.
try:
    # Checks the boot against the evidence that was valid when it was logged.
    boot = verifier.verify_boot_archive(boot_bytes, evidence_bytes)
    # Checks a buffered response that ends with its `stogas` object.
    receipt = boot.verify_response(sha256(request_bytes).digest(), response_bytes)
except VerificationError as error:
    print(error.code)  # A stable code, such as "receipt_content".
```

`verify_receipt(stogas_bytes, request_sha256, response_sha256)` takes a `stogas` object that you
saved on its own, with the hashes that you computed. To check current evidence instead, call
`verifier.refresh(evidence_bytes)`, then `verify_logged_boot` on the snapshot it returns. Each method
returns JSON bytes.
