The `stogas` package gives the OpenAI client a verified, encrypted `fetch`. The examples are
TypeScript. In JavaScript, leave out the type annotations. For browsers and edge Workers, see
[Browser and Workers](/docs/browser-workers).

## Install

```npm
npm install stogas openai
```

## Send a request

Create one transport and reuse it for every request. It checks the published evidence, opens an
attested [E2EE session](/docs/connection-modes#e2ee-over-https), and keeps your API key, provider
credentials, prompts and responses inside that session.

```ts
import OpenAI from 'openai';
import { StogasTransport } from 'stogas';

const apiKey = process.env.STOGAS_API_KEY;
if (!apiKey) throw new Error('Set STOGAS_API_KEY before running this example.');

const transport = await StogasTransport.create();
const client = new OpenAI(transport.openAIOptions(apiKey));

try {
	const response = await client.responses.create({
		model: 'chutes-gemma-4-31b-turbo',
		input: 'Say hello in one sentence.'
	});
	console.log(response.output_text);
} finally {
	await transport.close();
}
```

`openAIOptions` supplies the base URL, the API key and the `fetch` adapter. Requests go as binary
encrypted records to `https://e2ee.stogas.ai/v1/session`. The transport supports Chat Completions
and Responses. Other paths fail before credentials are sent.

## Stream and cancel

```ts
const cancellation = new AbortController();
// Your stop action calls cancellation.abort().
const stream = await client.chat.completions.create(
	{
		model: 'chutes-gemma-4-31b-turbo',
		messages: [{ role: 'user', content: 'Say hello.' }],
		stream: true
	},
	{ signal: cancellation.signal }
);
for await (const chunk of stream) {
	process.stdout.write(chunk.choices[0]?.delta.content ?? '');
}
```

Read the stream to the end and handle errors. The transport holds back the last event until it has
checked encrypted completion. See [Streaming](/docs/streaming) for errors, cancellation and
[progress](/docs/streaming#show-progress) with `onProgress`.

## Retries and timeouts

`openAIOptions` leaves the OpenAI client's retry and timeout settings unchanged. Set them for your
application:

```ts
const client = new OpenAI({ ...transport.openAIOptions(apiKey), maxRetries: 0, timeout: 600_000 });
```

The transport keeps HTTP status errors, `Retry-After` and `X-Should-Retry`, and never retries a
request itself. A request that was interrupted may already have run, so a retry can run it again.
Use `AbortSignal` to cancel.

## Options

```ts
const transport = await StogasTransport.create({
	maxConnections: 4,
	fetch: globalThis.fetch.bind(globalThis),
	onMetadata: (metadata) => console.log(metadata)
});
```

`StogasTransport.create` takes `baseURL`, `maxConnections`, `fetch`, `onMetadata` and `proxied`,
as [Options](/docs/sdk-overview#options) describes.

- `await transport.refreshEvidence()` loads new evidence now.
- `transport.evidenceSnapshot` shows the verified evidence, evidence URL, fetch time, verification
  time and status.
- `transport.subscribe(listener)` reports changes and returns an unsubscribe function.

## Receipts

Send `Stogas-Metadata: v2` to get a signed [receipt](/docs/receipts):

```ts
const response = await client.responses.create(
	{ model: 'chutes-gemma-4-31b-turbo', input: 'Say hello.' },
	{ headers: { 'Stogas-Metadata': 'v2' } }
);
```

The transport checks the receipt automatically. For a stream, read it to the end, because the
receipt comes last. A failed check throws an error and does not send the request again.

## Check evidence offline

The same Rust core checks evidence that your application supplies, without network requests:

```ts
import { EvidenceVerifier } from 'stogas';

const verifier = EvidenceVerifier.for_stogas('prod');
try {
	const snapshot = verifier.refresh(evidenceBytes);
	try {
		console.log(snapshot.summary());
		const boot = snapshot.verify_logged_boot(bootBytes, inclusionBytes);
		console.log(boot.node_id);
	} finally {
		snapshot.free();
	}
} finally {
	verifier.free();
}
```

Reuse one verifier when you accept evidence updates, so it keeps the key retirements and AMD
revocations it has learned. Free each snapshot when you finish with it.
