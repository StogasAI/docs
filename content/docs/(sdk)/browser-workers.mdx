The `stogas` package has entrypoints for browsers and Workers. Both verify the gateway on the
device, then send every request end-to-end encrypted over ordinary HTTPS. They use the same API as
the [JavaScript SDK](/docs/javascript).

```console
npm install stogas openai
```

## Browser

Initialize the WebAssembly module once, then reuse the transport and the OpenAI client:

```ts
import OpenAI from 'openai';
import init, { StogasTransport } from 'stogas/browser';

await init();
const transport = await StogasTransport.create();
const client = new OpenAI(transport.openAIOptions(userApiKey));
const cancellation = new AbortController(); // Your stop button calls cancellation.abort().

const stream = await client.chat.completions.create(
	{
		model: 'chutes-mistral-nemo-instruct-2407',
		messages: [{ role: 'user', content: 'Say hello in one sentence.' }],
		stream: true
	},
	{ signal: cancellation.signal }
);
for await (const chunk of stream) {
	console.log(chunk.choices[0]?.delta.content ?? '');
}
```

Close the transport with `await transport.close()` when the page no longer needs it.

<Callout type="warn">
	Each user must enter their own API key. Never put a shared key in browser code. Encryption cannot
	protect a key from other JavaScript that runs on the same page.
</Callout>

To show a status for each message, pass `onProgress`, as described in
[Streaming](/docs/streaming#show-progress). Import the `StogasRequestInit` type from `stogas/browser`
or `stogas/worker`.

## Cloudflare Workers

The Worker entrypoint loads its bundled WebAssembly module itself:

```ts
import OpenAI from 'openai';
import { StogasTransport } from 'stogas/worker';

const transport = await StogasTransport.create();
try {
	const client = new OpenAI(transport.openAIOptions(apiKey));
	const response = await client.responses.create({
		model: 'chutes-mistral-nemo-instruct-2407',
		input: 'Say hello.'
	});
	console.log(response.output_text);
} finally {
	await transport.close();
}
```

In a browser Web Worker, use the browser entrypoint and call `await init()` in the worker. A runtime
can suspend or discard a worker at any time, so keep a transport only while the worker runs.

## Options

`StogasTransport.create()` accepts:

| Option           | Default | Use                                                   |
| ---------------- | ------- | ----------------------------------------------------- |
| `maxConnections` | `4`     | The most encrypted sessions that the transport opens. |
| `baseURL`        |         | An HTTPS API address that ends in `/v1`.              |

Set `maxRetries` and `timeout` on the OpenAI client, and cancel requests with an `AbortSignal`.
Browsers keep each encrypted upload in memory until it is sent, so limit how many large uploads run
at once. See [Connection settings](/docs/sdk-overview#connection-settings).
