## Install

Use Rust 1.97.1 or later, `stogas` for the protected connection, and `async-openai` for request and response types.
Add these dependencies to your application:

```toml
[dependencies]
stogas = "0.1.0-alpha.1"
async-openai = { version = "0.42", default-features = false, features = ["chat-completion", "middleware"] }
reqwest = { version = "0.13", default-features = false }
futures-util = "0.3"
anyhow = "1"
tokio = { version = "1", features = ["macros", "rt-multi-thread", "signal"] }
```

The OpenAI client sends HTTP to the transport's private loopback URL. The transport handles the encrypted
connection to the gateway, so this local HTTP client does not need a TLS backend.

## Stream a response

Set `STOGAS_API_KEY` and `STOGAS_MODEL` to your key and a model ID from the catalog. Reuse one transport
across requests. This example cancels on Ctrl+C and closes the transport on success or error:

```rust
use async_openai::{
    Client,
    config::OpenAIConfig,
    middleware::ReqwestService,
    types::chat::{ChatCompletionRequestUserMessageArgs, CreateChatCompletionRequestArgs},
};
use futures_util::StreamExt as _;
use std::{io::Write as _, time::Duration};
use stogas::{Transport, TransportOptions};

fn client(base_url: &str, api_key: &str) -> anyhow::Result<Client<OpenAIConfig>> {
    let http = reqwest::Client::builder()
        .no_proxy()
        .redirect(reqwest::redirect::Policy::none())
        .retry(reqwest::retry::never())
        .timeout(Duration::from_secs(45 * 60))
        .build()?;
    let config = OpenAIConfig::new()
        .with_api_base(base_url)
        .with_api_key(api_key);
    // A plain service also disables async-openai's own retry layer.
    Ok(Client::with_config(config).with_http_service(ReqwestService::new(http)))
}

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let api_key = std::env::var("STOGAS_API_KEY")?;
    let model = std::env::var("STOGAS_MODEL")?;
    let supplied_base = std::env::var("STOGAS_BASE_URL").ok();
    let mut transport = if supplied_base.is_none() {
        Some(Transport::start(&TransportOptions::default())?)
    } else {
        None
    };
    let base_url = supplied_base
        .as_deref()
        .unwrap_or_else(|| transport.as_ref().unwrap().base_url());
    let result = async {
        let client = client(base_url, &api_key)?;
        let request = CreateChatCompletionRequestArgs::default()
            .model(model)
            .messages([ChatCompletionRequestUserMessageArgs::default()
                .content("Say hello in one sentence.")
                .build()?
                .into()])
            .build()?;
        let mut stream = client.chat().create_stream(request).await?;
        loop {
            tokio::select! {
                chunk = stream.next() => {
                    let Some(chunk) = chunk else { break };
                    for choice in chunk?.choices {
                        if let Some(text) = choice.delta.content {
                            print!("{text}");
                            std::io::stdout().flush()?;
                        }
                    }
                }
                signal = tokio::signal::ctrl_c() => {
                    signal?;
                    anyhow::bail!("cancelled; delivery is incomplete");
                }
            }
        }
        println!();
        Ok(())
    }
    .await;
    if let Some(transport) = &mut transport {
        transport.close();
    }
    result
}
```

`ReqwestService` bypasses `async-openai`'s default retry layer. The HTTP client also disables retries,
redirects and system proxies. Keep these settings: a lost response does not prove that an inference
never ran. Choose the timeout to suit your application.

The transport withholds stream completion until its required verification succeeds. Text can arrive
earlier; cancellation or a verification error means delivery is incomplete.

## Buffered responses

Use the same client and request with `create` instead of `create_stream`:

```rust
let response = client.chat().create(request).await?;
for choice in response.choices {
    if let Some(text) = choice.message.content {
        println!("{text}");
    }
}
```

## Transport options

`TransportOptions::default()` selects native attested TLS in production, with up to four connections
opened as needed. Use `SecurityMode::E2ee` for application encryption over ordinary HTTPS. The optional
origin override cannot change the trusted signing keys or evidence endpoints.

`refresh_bundle()` requests an explicit evidence refresh; there is no polling task. `close()` waits
for bounded graceful cleanup. Dropping the transport signals cleanup without blocking.

Send `Stogas-Metadata: v1` to request the final `stogas` metadata and automatic receipt verification.
The [complete example](https://github.com/StogasAI/stogas/tree/main/examples/rust-openai) includes
client integration tests.

## Options

```rust
stogas::TransportOptions {
    security: stogas::SecurityMode::E2ee,
    max_connections: 4,
    ..Default::default()
}
```

`base_url` accepts an HTTPS origin. Configure retry middleware and deadlines on the HTTP/OpenAI client. The example deliberately uses `ReqwestService` without retry middleware.

Native attested TLS is the default; this example selects E2EE. See
[Connection settings](/docs/sdk-overview#connection-settings) for limits that apply to every SDK.
