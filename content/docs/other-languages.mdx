---
title: More Languages
description: Use Stogas from other runtimes.
---

The native SDK exposes a bounded C ABI for runtimes without a dedicated binding. Start
`StogasTransport`, keep its handle alive, and configure your OpenAI-compatible client with the
returned base URL.

```json
{
	"security": "both",
	"bundle_refresh_interval_seconds": 300,
	"base_url": "https://api.stogas.ai",
	"bundle_url": "https://evidence.stogas.ai/bundles/latest.json"
}
```

Encode this complete configuration as UTF-8 JSON and pass it to `stogas_transport_start`. Keep the
returned handle, use `stogas_transport_refresh` for an immediate refresh, and release it with
`stogas_transport_free`.

Applications that need the raw trust set can bridge the packaged C ABI:

| Runtime           | Native bridge                                                          |
| ----------------- | ---------------------------------------------------------------------- |
| Scala and Clojure | Java Foreign Function & Memory API or JNA                              |
| F#                | .NET P/Invoke                                                          |
| Objective-C       | Native C interoperability                                              |
| Dart and Flutter  | `dart:ffi`                                                             |
| Zig               | `@cImport`                                                             |
| PHP               | PHP FFI where enabled                                                  |
| Julia             | `ccall`                                                                |
| Haskell           | Standard Haskell FFI                                                   |
| OCaml             | `ctypes`                                                               |
| LuaJIT            | LuaJIT FFI                                                             |
| Elixir and Erlang | A supervised Port; use a NIF only when process isolation is acceptable |

The ABI returns bounded JSON envelopes, so a bridge owns only allocation and type conversion. It must not reimplement transport or cryptographic policy.
