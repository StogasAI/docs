## Install

```kotlin
implementation("com.openai:openai-java:4.43.0")
```

Start [`stogas-verify serve`](/docs/cli), then initialize the official client:

```java
OpenAIClient client = OpenAIOkHttpClient.builder()
    .apiKey(System.getenv("STOGAS_API_KEY"))
    .baseUrl(System.getenv().getOrDefault(
        "STOGAS_BASE_URL",
        "http://127.0.0.1:8787/v1"
    ))
    .build();

Response response = client.responses().create(
    ResponseCreateParams.builder()
        .model("openai/gpt-5-mini")
        .input("Say hello in one sentence.")
        .build()
);
```

Java 22+ applications that need the raw trust set can load the packaged Stogas native library with the Foreign Function & Memory API. Older JVM applications can use JNA or a small JNI adapter. Scala and Clojure use the same JVM path.
