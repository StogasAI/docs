## Install

```console
dotnet add package OpenAI
```

Start [`stogas-verify serve`](/docs/cli), then initialize a client with the local endpoint:

```csharp
using OpenAI.Chat;
using System.ClientModel;

var baseUrl = Environment.GetEnvironmentVariable("STOGAS_BASE_URL")
    ?? "http://127.0.0.1:8787/v1";

ChatClient client = new(
    model: "openai/gpt-5-mini",
    credential: new ApiKeyCredential(
        Environment.GetEnvironmentVariable("STOGAS_API_KEY")!
    ),
    options: new OpenAIClientOptions { Endpoint = new Uri(baseUrl) }
);

ChatCompletion response = await client.CompleteChatAsync(
    "Say hello in one sentence."
);
```

C# and F# applications that need the raw trust set can call the packaged native verifier with `LibraryImport` or `DllImport` / P/Invoke.
