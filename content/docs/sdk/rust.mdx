## Install

```console
cargo add stogas-verifier
```

## Verify a bundle

```rust
use std::time::{SystemTime, UNIX_EPOCH};
use stogas_verifier::{Environment, Verifier};

let bundle = std::fs::read("bundle.json")?;
let now = i64::try_from(
    SystemTime::now().duration_since(UNIX_EPOCH)?.as_millis()
)?;

let verified = Verifier::default().verify_bundle(
    &bundle,
    now,
    &Environment::stogas(),
)?;

println!("{}", verified.bundle.nodes.len());
```

The core accepts one captured wall-clock value so tests and audits remain deterministic. Packaged language adapters capture that value automatically.

## Send requests

OpenAI does not publish an official Rust client. Point your existing OpenAI-compatible Rust client at the URL printed by [`stogas-verify serve`](/docs/cli), or call that local `/v1` endpoint with your current HTTP stack.
