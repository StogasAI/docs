## Install

```ruby
gem "openai"
```

Start [`stogas-verify serve`](/docs/cli), then use its base URL:

```ruby
require "openai"

client = OpenAI::Client.new(
  api_key: ENV.fetch("STOGAS_API_KEY"),
  base_url: ENV.fetch("STOGAS_BASE_URL", "http://127.0.0.1:8787/v1")
)

response = client.responses.create(
  model: "openai/gpt-5-mini",
  input: "Say hello in one sentence."
)

puts response.output_text
```

Ruby applications that need the raw trust set can load the native C library with `Fiddle` or the `ffi` gem. See [C and C++](/docs/sdk/c-cpp) for the ABI contract.
