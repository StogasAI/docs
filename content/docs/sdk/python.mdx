## Install

```console
pip install stogas-verifier openai
```

The verifier ships as a CPython 3.10+ stable-ABI extension built with PyO3.

## Verify a bundle

```python
import json
from urllib.request import urlopen
from stogas_verifier import Verifier

with urlopen("https://evidence.stogas.ai/bundles/latest.json") as response:
    bundle = response.read()

verified = json.loads(Verifier().verify_bundle(bundle))
print(verified["bundle"]["nodes"])
```

## OpenAI client

Start [`stogas-verify serve`](/docs/cli), then initialize the official OpenAI client with the local base URL:

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["STOGAS_API_KEY"],
    base_url=os.getenv("STOGAS_BASE_URL", "http://127.0.0.1:8787/v1"),
)

response = client.responses.create(
    model="openai/gpt-5-mini",
    input="Say hello in one sentence.",
)

print(response.output_text)
```
