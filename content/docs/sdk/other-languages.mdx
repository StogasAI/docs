---
title: More Languages
description: Use the CLI everywhere or bridge the native C ABI.
---

Any OpenAI-compatible client can use the URL printed by [`stogas-verify serve`](/docs/cli). Change the client's API key and base URL; its request types, streaming, and model calls stay the same.

Applications that need the raw trust set can bridge the packaged C ABI:

| Runtime           | Native bridge                                                          |
| ----------------- | ---------------------------------------------------------------------- |
| Scala and Clojure | Java Foreign Function & Memory API or JNA                              |
| F#                | .NET P/Invoke                                                          |
| Objective-C       | Native C interoperability                                              |
| Dart and Flutter  | `dart:ffi`                                                             |
| Zig               | `@cImport`                                                             |
| PHP               | PHP FFI where enabled                                                  |
| Julia             | `ccall`                                                                |
| Haskell           | Standard Haskell FFI                                                   |
| OCaml             | `ctypes`                                                               |
| LuaJIT            | LuaJIT FFI                                                             |
| Elixir and Erlang | A supervised Port; use a NIF only when process isolation is acceptable |

The ABI returns a bounded JSON envelope, so a bridge only owns allocation and type conversion. It must not reimplement cryptographic policy.
