---
title: Swift
description: Call the verified endpoint from Apple platforms.
---

OpenAI does not publish an official Swift client. Start [`stogas-verify serve`](/docs/cli) on macOS and use its URL with `URLSession` or an OpenAI-compatible client:

```swift
let baseURL = ProcessInfo.processInfo.environment["STOGAS_BASE_URL"]
    ?? "http://127.0.0.1:8787/v1"
let apiKey = ProcessInfo.processInfo.environment["STOGAS_API_KEY"]!

var request = URLRequest(url: URL(string: "\(baseURL)/responses")!)
request.httpMethod = "POST"
request.setValue("Bearer \(apiKey)", forHTTPHeaderField: "Authorization")
request.setValue("application/json", forHTTPHeaderField: "Content-Type")
request.httpBody = try JSONEncoder().encode([
    "model": "openai/gpt-5-mini",
    "input": "Say hello in one sentence."
])

let (data, response) = try await URLSession.shared.data(for: request)
```

Swift and Objective-C can also import `stogas_verifier.h` directly when an app needs the raw trust set. iOS cannot rely on a CLI running on another machine; embed the verifier and an application transport appropriate to the app's threat model.
