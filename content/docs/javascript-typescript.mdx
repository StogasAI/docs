## Install

```console
npm install @stogas/verifier openai
```

## Verify a bundle

```ts
import { Verifier } from '@stogas/verifier';

const response = await fetch('https://evidence.stogas.ai/bundles/latest.json');
if (!response.ok) throw new Error(`bundle fetch failed: ${response.status}`);

const verifier = new Verifier();
try {
	const bundle = new Uint8Array(await response.arrayBuffer());
	const verified = verifier.verify_bundle(bundle);
	console.log(verified.bundle.nodes);
} finally {
	verifier.free();
}
```

Keep one `Verifier` instance when checking successive bundles. It reuses verified immutable release evidence in memory.

These imports work unchanged in JavaScript and TypeScript on Node, Bun, and Deno.

## OpenAI client

Create one `StogasTransport`, give its options to the OpenAI client, and reuse both objects:

```ts
import OpenAI from 'openai';
import { StogasTransport } from '@stogas/verifier';

const transport = await StogasTransport.create({
	baseURL: 'https://api.stogas.ai/v1',
	bundleURL: 'https://evidence.stogas.ai/bundles/latest.json',
	bundleRefreshIntervalSeconds: 60,
	fetch: globalThis.fetch.bind(globalThis)
});
const client = new OpenAI(transport.openAIOptions(process.env.STOGAS_API_KEY!));

try {
	const changed = await transport.refreshBundle();
	console.log(changed ? 'New trust snapshot' : 'Trust snapshot unchanged');

	const response = await client.responses.create({
		model: 'openai/gpt-5-mini',
		input: 'Say hello in one sentence.'
	});

	console.log(response.output_text);
} finally {
	transport.close();
}
```

This is the complete Fetch-transport configuration. It always uses E2EE; native TLS and `both`
are available through the Rust transport used by the Python, Go, Rust, and C-family SDKs.

The low-level `Verifier` remains useful when an application needs the verified gateway set or wants to check a compact response receipt itself. Protected inference does not require maintaining a second OpenAI client wrapper.

## Verify a response receipt

After `verify_bundle`, pass the decoded receipt JSON and the exact plaintext request and response bytes to the same verifier:

```ts
const receipt = verifier.verify_response_proof(proofBytes, requestBytes, responseBytes);
console.log(receipt.request_sha256, receipt.response_sha256);
```

For an older gateway, call `verify_historical_response_proof` with its immutable Trust Center ledger record instead of relying on an active bundle. Decode the base64url `X-Stogas-Proof` header before passing it to the verifier; the final `stogas.proof` streaming event already contains the receipt JSON.
