Google Cloud deployments run Claude in your Google Cloud project. Google bills you for inference,
and we charge the [BYOK fee](/docs/byok#billing). Agent Platform is the service that Google called
Vertex AI until April 2026.

| Deployment ID suffix | Offering                                          | Who runs Claude, and where    |
| -------------------- | ------------------------------------------------- | ----------------------------- |
| None                 | Agent Platform, global endpoint                   | Google, in any region         |
| `-us`                | Agent Platform, US multi-region                   | Google, in the United States  |
| `-eu`                | Agent Platform, EU multi-region                   | Google, in the European Union |
| `-anthropic-hosted`  | Claude Models on Google Cloud (Anthropic managed) | Anthropic                     |

## Create a credential

Give a service account `roles/aiplatform.user` for Agent Platform, and also `roles/claude.user`
for Claude Models on Google Cloud. Add its JSON key in [BYOK](/docs/byok), then delete the key
file. Google blocks service account keys by default in organizations created since May 3, 2024, so
an organization policy administrator may have to allow them in your project.

## Customer encryption

With [customer encryption](/docs/byok#customer-encryption), the CLI encrypts the key file:

```bash
stogas encrypt --key providers --organization <organization-id> \
  --purpose byok/google-cloud --input key.json --output credential.json
```

For Claude Models on Google Cloud, encrypt a credential document with your workspace ID instead:

```bash
jq --arg workspace wrkspc_... '{
  schema: "stogas.google-cloud-byok.v1",
  projectId: .project_id,
  clientEmail: .client_email,
  privateKeyId: .private_key_id,
  privateKey: (.private_key | gsub("-----[A-Z ]+-----|\\s"; "")),
  workspaceId: $workspace
}' key.json > google.json
stogas encrypt --key providers --organization <organization-id> \
  --purpose byok/google-cloud --input google.json --output credential.json
```

Then delete `key.json` and `google.json`, and add `credential.json` in [BYOK](/docs/byok).

## Differences from Anthropic

Claude Models on Google Cloud works as on [Anthropic](/docs/providers/anthropic). On Agent
Platform, send files inline, because file URLs and file IDs are rejected. `web_search` and
`web_fetch` are not available.

On Agent Platform, a `json_schema` response format and strict tools work only once
`structured_outputs` is an allowed value of your organization's
`constraints/vertexai.allowedPartnerModelFeatures` policy, which Google blocks by default.
