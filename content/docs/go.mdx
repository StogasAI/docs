## Install

```console
go get github.com/StogasAI/verifier/go
go get github.com/openai/openai-go/v3
```

The Stogas package is a narrow cgo binding. Tagged releases include the Rust library for each supported target.

## Verify a bundle

```go
bundle, err := os.ReadFile("bundle.json")
if err != nil { return err }

v, err := verifier.New()
if err != nil { return err }
defer v.Close()

verifiedJSON, err := v.VerifyBundle(bundle)
if err != nil { return err }
fmt.Println(string(verifiedJSON))
```

## OpenAI client

Create one transport when your service starts, reuse its base URL across OpenAI clients, and close
it during graceful shutdown:

```go
transport, err := stogas.NewTransport(stogas.TransportOptions{
    Security:                     "both",
    BundleRefreshIntervalSeconds: 300,
    BaseURL:                      "https://api.stogas.ai",
    BundleURL:                    "https://evidence.stogas.ai/bundles/latest.json",
})
if err != nil { return err }
defer transport.Close()

changed, err := transport.RefreshBundle()
if err != nil { return err }

baseURL, err := transport.BaseURL()
if err != nil { return err }

client := openai.NewClient(
    option.WithAPIKey(os.Getenv("STOGAS_API_KEY")),
    option.WithBaseURL(baseURL),
)

response, err := client.Responses.New(context.Background(), responses.ResponseNewParams{
    Model: "openai/gpt-5-mini",
    Input: responses.ResponseNewParamsInputUnion{
        OfString: openai.String("Say hello in one sentence."),
    },
})
```

The struct above shows every transport option. Zero-valued fields use the public Stogas defaults.

## Verify a response receipt

Reuse the verifier after `VerifyBundle`:

```go
receipt, err := v.VerifyResponseProof(proofJSON, requestBody, responseBody, "")
if err != nil { return err }
fmt.Println(string(receipt))
```

Call `VerifyHistoricalResponseProof` with an immutable Trust Center ledger record for a gateway that is no longer active. Pass the E2EE transcript SHA-256 as the final argument when the exchange was encrypted.
