---
title: Swift
description: Use Stogas from Apple platforms.
---

Swift and Objective-C import the packaged Stogas header directly. Start `StogasTransport` in-process and use its returned base URL with `URLSession` or an OpenAI-compatible client:

```swift
let configuration: [String: Any] = [
    "security": "both",
    "bundle_refresh_interval_seconds": 300,
    "base_url": "https://api.stogas.ai",
    "bundle_url": "https://evidence.stogas.ai/bundles/latest.json"
]
let configurationData = try JSONSerialization.data(withJSONObject: configuration)
let stogasTransport = try StogasTransport.start(configurationData)
defer { stogasTransport.close() }

let changed = try stogasTransport.refreshBundle()
let baseURL = stogasTransport.baseURL
let apiKey = ProcessInfo.processInfo.environment["STOGAS_API_KEY"]!

var request = URLRequest(url: URL(string: "\(baseURL)/responses")!)
request.httpMethod = "POST"
request.setValue("Bearer \(apiKey)", forHTTPHeaderField: "Authorization")
request.setValue("application/json", forHTTPHeaderField: "Content-Type")
request.httpBody = try JSONEncoder().encode([
    "model": "openai/gpt-5-mini",
    "input": "Say hello in one sentence."
])

let (data, response) = try await URLSession.shared.data(for: request)
```

The dictionary above contains every native transport option. The same header exposes explicit
bundle and receipt verification.
