A coding agent that takes an OpenAI-compatible base URL works with `https://api.stogas.ai/v1` and
an [API key](/docs/api-keys). Its `model` setting takes any ID that
[`/v1/models`](/docs/models#find-a-model) lists. Codex and OpenCode send a session ID with each
request, so each of their conversations is one [session](/docs/request-records#sessions).

## Codex

```toml title="~/.codex/config.toml"
model = "claude-sonnet-5-5"
model_provider = "stogas"
web_search = "live"

[model_providers.stogas]
name = "Stogas"
base_url = "https://api.stogas.ai/v1"
env_key = "STOGAS_API_KEY"
stream_max_retries = 0
```

- Codex adds [web search](/docs/model-tools#hosted-tools) to every request. With `"live"`, every
  model that runs web search can use it. Codex's default, `"cached"`, searches only OpenAI's index,
  so requests to other models fail with `400`, and `"indexed"` fails on every model.
- A model with no deployment that runs web search returns `unsupported_tool`. Set
  `web_search = "disabled"` to use it. [Compare providers](/docs/providers) shows which providers
  run web search.
- Codex retries a dropped stream up to 5 times, and each retry runs and bills the model again.
  `stream_max_retries = 0` turns that off.

## OpenCode

```jsonc title="opencode.jsonc"
{
	"$schema": "https://opencode.ai/config.json",
	"providers": {
		"stogas": {
			"name": "Stogas",
			"env": ["STOGAS_API_KEY"],
			"package": "@opencode/ai/providers/openai-compatible",
			"settings": { "baseURL": "https://api.stogas.ai/v1" },
			"models": { "claude-sonnet-5-5": { "name": "Claude Sonnet 5.5" } }
		}
	}
}
```

Select the model as `stogas/claude-sonnet-5-5`, and add each model that you use to `models`.

## Claude Code

Claude Code sends only Anthropic's Messages format, which the API does not accept, so it cannot
connect.
