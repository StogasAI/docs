A coding agent that takes an OpenAI-compatible base URL works with `https://api.stogas.ai/v1` and
an [API key](/docs/api-keys). Its `model` setting takes any ID that
[`/v1/models`](/docs/models#find-a-model) lists. Codex, OpenCode and Claude Code send a session ID
with each request, so each of their conversations is one [session](/docs/request-records#sessions).

## Codex

```toml title="~/.codex/config.toml"
model = "claude-sonnet-5-5"
model_provider = "stogas"
web_search = "live"

[model_providers.stogas]
name = "Stogas"
base_url = "https://api.stogas.ai/v1"
env_key = "STOGAS_API_KEY"
stream_max_retries = 0
```

- Codex adds [web search](/docs/model-tools#hosted-tools) to every request. With `"live"`, every
  model that runs web search can use it. `"cached"` searches only OpenAI's index, so requests to
  other models fail with `400`, and `"indexed"` fails on every model.
- A model with no deployment that runs web search returns `unsupported_tool`. Set
  `web_search = "disabled"` to use it. [Compare providers](/docs/providers) shows which providers
  run web search.
- Codex retries a dropped stream several times, and each retry runs and bills the model again.
  `stream_max_retries = 0` turns that off.

## OpenCode

```jsonc title="opencode.jsonc"
{
	"$schema": "https://opencode.ai/config.json",
	"providers": {
		"stogas": {
			"name": "Stogas",
			"env": ["STOGAS_API_KEY"],
			"package": "@opencode/ai/providers/openai-compatible",
			"settings": { "baseURL": "https://api.stogas.ai/v1" },
			"models": { "claude-sonnet-5-5": { "name": "Claude Sonnet 5.5" } }
		}
	}
}
```

Select the model as `stogas/claude-sonnet-5-5`, and add each model that you use to `models`.

## Claude Code

```json title="~/.claude/settings.json"
{
	"env": {
		"ANTHROPIC_BASE_URL": "https://api.stogas.ai",
		"ANTHROPIC_AUTH_TOKEN": "<your API key>",
		"CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY": "1",
		"CLAUDE_CODE_GATEWAY_HINT_HEADERS": "1"
	}
}
```

- Claude Code calls the [Messages API](/docs/reference/anthropic-compatible/createMessage), so it
  can use the models whose deployments serve it. With model discovery on, `/model` lists them.
- With hint headers on, the [records](/docs/request-records#agents) of a subagent's requests name
  its kind, such as `Explore`.
- If `ANTHROPIC_API_KEY` holds another key, such as one of Anthropic's, Claude Code sends both keys
  and every request fails with `400`. Remove it from the environment that runs Claude Code.
- The API has no token counting endpoint, so `/context` shows estimates.
- To verify the gateway and encrypt each request, run [`stogas serve`](/docs/cli#serve) and set
  `ANTHROPIC_BASE_URL` to the Anthropic base URL that it prints.
