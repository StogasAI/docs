Our AI gateway gives you one OpenAI-compatible API for models from many
[providers](/docs/providers), with spending limits, routing rules and request analytics for your
organization. The gateway runs inside AMD SEV-SNP confidential virtual machines, and our SDKs check
its software and hardware before they send your API key or prompt.

## How a request works

<Steps>
<Step>

### Your client sends the request

Any OpenAI-compatible client can call `https://api.stogas.ai/v1` with an API key. With our
SDK, the request goes through a connection that ends inside a verified gateway.

</Step>
<Step>

### The gateway applies your policies

The gateway checks the key, balance, limits and access rules. It selects a deployment and runs
plugins such as PII redaction.

</Step>
<Step>

### The provider runs the model

The gateway sends the request to the selected provider with a Stogas-managed credential or your
own provider key.

</Step>
<Step>

### You receive the response

The response returns as one body or a stream. Analytics records usage and cost, but not the prompt
or response. You can also request a signed receipt.

</Step>
</Steps>
