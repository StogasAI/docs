---
title: Policies
description: Set budgets, control traffic, choose providers, and add redaction rules.
---

A policy is a JSON document that controls how an API key can be used. Save shared rules on an
organization or grant, and add restrictions to individual keys. Every request must satisfy all
policies that apply to it.

This policy sets a $10 lifetime spend cap:

```json title="policy.json"
{
	"version": 1,
	"limits": {
		"spend": {
			"lifetimeUsd": "10.00"
		}
	}
}
```

On an organization, that $10 is shared across all its keys. On a grant, it is shared across the
grant's member keys. On a key, it applies only to that key. A key cannot override a parent cap.

Only `version` is required. Add the settings you need and leave out the rest.

## Look up the syntax

The [policy reference](/docs/policies/reference) lists every setting, its type, and its default.
The [routing field reference](/docs/policies/routing-fields) lists every field a query can read.
Use the [JSON Schema](https://stogas.ai/schemas/key-config-v1.json) for editor completion.

A policy restricts an existing credential. It does not create a key, grant membership, enable a
disabled key, or add funds. See [API keys and grants](/docs/api-keys) for credential management
and [BYOK](/docs/byok) for provider credentials.
