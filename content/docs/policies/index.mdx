---
title: Policies
description: Control spending, providers, access and plugins for your API keys.
---

A policy is a JSON document that controls which requests an API key can make, how much it can use,
what text reaches a provider and where request data goes. You can save a policy on an organization,
folder, grant, role, member, provider credential or key. Every request follows all the policies
that apply to it.

This policy allows only providers that do not train on prompts, and caps spending at $10:

```json title="policy.json"
{
	"routing": {
		"filter": "deployment.dataHandling.trainingUse == false"
	},
	"limits": {
		"spend": { "lifetimeUsd": "10" }
	}
}
```

On an organization, all its keys share the $10. On a key, the $10 is for that key only. A key
policy cannot raise a cap that an organization or grant policy sets.

## Plugins

| Plugin                 | Use it to                                                                                                |
| ---------------------- | -------------------------------------------------------------------------------------------------------- |
| `stogasTextExtraction` | [Turn text files into prompt text](/docs/input-files#turn-text-files-into-prompt-text) before redaction. |
| `stogasRedaction`      | [Replace sensitive text](/docs/pii-redaction) before Stogas calls the provider.                          |
| `stogasExport`         | [Send each request and response](/docs/export) to your webhook.                                          |

To keep plugin settings private, such as redaction terms or webhook tokens,
[encrypt them](/docs/customer-encryption#encrypt-plugin-settings).
