A request policy adds settings to one request. It can add restrictions and replace
[defaults](/docs/policies/rules#defaults), but it cannot remove a required
setting from a saved policy.

## Grant permission

Request policies are off until a saved policy allows them. Set `delegation.request` on any saved
scope that applies to the key:

```json title="Saved policy"
{
	"delegation": {
		"request": ["routing.filter", "routing.sort", "plugins.redaction"]
	}
}
```

- Use `true` for every section, or a list of section paths. A path such as `routing` allows the
  whole section.
- When several policies set `delegation.request`, a section must be allowed by all of them.
- A rule needs permission for every setting in it, whether or not its condition matches.
- An encrypted export or redaction needs permission for that plugin and for `plugins.encrypted`,
  which lets it hide its settings.

## Add a policy to a request

Send `policy` in the body of a Chat Completions or Responses request:

```json title="Chat Completions request"
{
	"model": "gpt-5.6-sol",
	"messages": [{ "role": "user", "content": "Reply to élise@contoso.com." }],
	"policy": {
		"routing": { "filter": "provider.id == 'openai'" },
		"plugins": { "redaction": { "email_address": true } }
	}
}
```

The provider receives `Reply to <EMAIL_ADDRESS>.`. The gateway removes `policy` from the request before
it calls the provider.

```json title="Responses request: cheapest output first"
{
	"model": "gpt-5.6-sol",
	"input": "Hello",
	"policy": {
		"routing": {
			"sort": [{ "by": "deployment.pricing.output_tokens.per_mill_tokens", "direction": "asc" }]
		}
	}
}
```

A request sort orders the deployments that the required sorts of other policies leave tied, and
default sorts order the ties that it leaves. See
[Orders from several policies](/docs/policies/routing#orders-from-several-policies).

## What a request policy can contain

- `access`, `input`, `timeouts`, `routing`, `plugins` and `rules`, if permitted.
- [An encrypted export or redaction](/docs/customer-encryption#encrypt-plugin-settings) whose key
  the organization registered. Send the key in `encryption_keys`.
- Up to 16 KiB, as sent.

`limits` and `delegation` are rejected, also inside rules. Save limits on a key or another
resource.

## Rejected policies

| Status | Cause                                                                         |
| ------ | ----------------------------------------------------------------------------- |
| `403`  | `permission_denied`: a section is not allowed by `delegation.request`.        |
| `400`  | The policy is invalid, too large, or its sort conflicts with a required sort. |
